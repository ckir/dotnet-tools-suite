# Security Policy

## Reporting a vulnerability

Please report vulnerabilities via a private
[GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories)
for this repository. Do not open a public issue for security reports.

## Scope

Supported: the latest `main` branch of `src/apps/*` and `src/libs/*`.
